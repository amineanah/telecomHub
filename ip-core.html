EPC (Evolved Packet Core)

4G core network architecture providing packet-only data services with simplified topology and improved latency. Foundation of LTE networks.

  • MME: Mobility Management Entity
  • S/P-GW: Serving/PDN Gateways
  • HSS: Home Subscriber Server
  • PCRF: Policy & Charging Rules Function
  • Topology: Flattened vs 3G hierarchy
  • Latency: Reduced with direct IP connectivity

5G Core (5GC)

Next-generation service-based architecture with microservices, virtualization, and cloud-native design. Enables network slicing and advanced services.

  • AMF: Access & Mobility Management Function
  • SMF: Session Management Function
  • UPF: User Plane Function
  • UDM: Unified Data Management
  • Network Slicing: Multiple isolated networks
  • Edge Computing: MEC integration for low latency

Network Slicing

Virtualized end-to-end networks optimized for specific use cases. Enables diverse service requirements (eMBB, URLLC, mMTC) on same infrastructure.

  • eMBB Slice: Enhanced Mobile Broadband
  • URLLC Slice: Ultra-Reliable Low Latency
  • mMTC Slice: Massive Machine Type Communication
  • Isolation: Independent traffic handling
  • Resource Allocation: Dynamic per slice requirements
  • SLA Management: Per-slice performance guarantees

SDN & NFV Integration

Software-Defined Networking (SDN) provides programmable control plane. Network Function Virtualization (NFV) runs network functions on standard hardware. Together they enable flexible, scalable, cost-effective core networks.

Multi-Access Edge Computing (MEC)

Moves computation closer to users, reducing latency and backhaul congestion. Enables ultra-low latency applications, local content delivery, and context-aware services. Critical for AR/VR and IoT.

IMS (IP Multimedia Subsystem)

Architecture for delivering multimedia services (voice, video, messaging) over IP. Provides Rich Communication Services (RCS), VoLTE (Voice over LTE), and video calling. Bridges legacy and IP-based services.

Policy & Charging

PCRF in 4G and Policy Function in 5G manage traffic policies, QoS enforcement, and real-time charging. Enables service-aware network management and monetization of diverse services.
